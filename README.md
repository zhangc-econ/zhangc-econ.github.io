# zhangc-econ.github.io

Personal website of Zhang Chen: https://zhangc-econ.github.io

The whole site is one file, `index.html`. To update it:

- **Edit text or links:** open `index.html` on GitHub, click the pencil icon, edit, and click "Commit changes". The site updates within a minute or two.
- **Add a paper or new CV:** upload the PDF into the `files/` folder ("Add file" → "Upload files"), then link to it in `index.html` as `files/NAME.pdf`.
- **Photo:** `images/photo.jpg`.

Keep existing PDFs in `files/` at their current names: other websites and search engines link to them directly.
